# Prism Gate

Tap to cycle the gate’s hue. Matching shards pass through. Wrong color cracks the glass.

## How to play

- Tap, click, or press Space to cycle magenta, cyan, and gold
- Let matching shards hit the prism — combos pay more
- Three cracks and the gate shatters
